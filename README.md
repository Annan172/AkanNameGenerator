# Akan Name Generator

The Akan Name Generator is a simple web-based application that generates a traditional **Akan name** based on a user’s **date of birth** and **gender**. Akan names originate from Ghanaian culture, where children are named according to the day of the week they were born.

---

## 🌍 Live Site
https://Annan172.github.io/AkanNameGenerator/

---

## ✨ Features
- Input date of birth
- Gender selection (male or female)
- Automatic calculation of day of the week
- Displays the correct Akan name
- Form validation for empty or invalid inputs
- Clean and responsive user interface
