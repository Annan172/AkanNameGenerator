AKAN NAME GENERATOR

Introduction

The Akan Name Generator website is an interactive web application designed to generate traditional Akan names based on a user’s date of birth and gender. Rooted in Ghanaian cultural practices, the application reflects the Akan naming system, where names are assigned according to the day of the week on which a person is born. Users simply input their birth date and select their gender, after which the system calculates the corresponding day of the week using JavaScript logic and displays the appropriate Akan name. The website features a clean and user-friendly interface, responsive design, and form validation to ensure accurate input and meaningful output. By combining cultural education with modern web technologies, the application demonstrates practical use of HTML for structure, CSS for styling, and JavaScript for functionality, while also showcasing version control and deployment through GitHub and GitHub Pages.
